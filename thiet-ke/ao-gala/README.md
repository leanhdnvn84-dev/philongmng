# Mẫu áo polo trắng – Gala gặp mặt Nguyễn Hiền 2000 – 2003

- `mau-ao-polo-trang-mo-phong.png`: ảnh mô phỏng áo (mặt trước + mặt sau; lưng để trơn).
- `in-tay-trai-8x8cm-300dpi.png`: huy hiệu tay áo trái (23 năm · Gala 14.11.2026), nền trong suốt, 8×8 cm ở 300 dpi, đặt giữa bắp tay ngoài, cách vai ~8 cm.
- `in-mat-truoc-10x10cm-300dpi.png`: file in ngực trái, nền trong suốt, 10×10 cm ở 300 dpi.
- `ao.html`: bản vẽ gốc (SVG + font Google). Sửa chữ/màu trong file rồi dựng lại ảnh:
  `PLAYWRIGHT=/opt/node-tools/node_modules/playwright node thiet-ke/ao-gala/render.js thiet-ke/ao-gala`
