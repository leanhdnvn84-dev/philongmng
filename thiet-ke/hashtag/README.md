# 15 hashtag Gala Nguyễn Hiền 2000–2003

- `hashtag-A4-300dpi.png` – bảng A4 in 300dpi (in màu, cắt ra làm bảng cầm chụp ảnh).
- `hashtag-xem-truoc.png` – bản xem nhanh gửi Zalo.
- `the/01.png … 15.png` – từng thẻ riêng (nền trong suốt) để in khổ lớn / dán backdrop.
- Sửa chữ trong mảng `T` của `hashtag.html` (dấu `|` = chỗ xuống dòng), rồi chạy:
  `PLAYWRIGHT=/opt/node-tools/node_modules/playwright node render.js`
