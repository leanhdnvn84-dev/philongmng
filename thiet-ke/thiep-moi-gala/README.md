# Thiệp mời Gala – Nguyễn Hiền 2000 – 2003 (bản in)

Khổ **A5 dọc 148 × 210 mm**, cùng tông xanh nhà trường với backdrop sân khấu.

| File | Dùng khi |
|---|---|
| `thiep-moi-A5-2-trang.pdf` | **Gửi tiệm in file này.** Trang 1 mời các bạn, trang 2 mời Thầy/Cô (vector, chữ sắc). |
| `moi-ban-A5-300dpi.png`, `moi-thay-co-A5-300dpi.png` | Tiệm chỉ nhận ảnh: 300 dpi. |
| `*-xem-truoc.png` | Ảnh nhỏ gửi Zalo duyệt mẫu. |

- Tên người nhận, lớp và **địa điểm** để dòng chấm cho ghi tay (nhà hàng chưa chốt). Có tên nhà hàng → điền `NHA_HANG`, `DIA_CHI` trong `thiep-moi.html` rồi xuất lại.
- Giấy gợi ý: couché/mỹ thuật 250–300 gsm, cán mờ.
- Xuất lại: `PLAYWRIGHT=/opt/node-tools/node_modules/playwright node render.js 1` (xem trước) và `… render.js 3.125` (300 dpi + PDF).
